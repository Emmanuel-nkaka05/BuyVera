# Veracart - Django E-Commerce Platform

Veracart is a fully functional, multi-vendor e-commerce platform built with Django. It features a modern, responsive user interface, a complete shopping cart flow, seller product management, and simulated payment processing. 

## 🚀 Features

- **User Authentication & Roles:** Separate registration and login flows for Buyers and Sellers.
- **Product Catalog:** Dynamic product listings, categories, and search functionality.
- **Product Variations:** Support for colors and sizes.
- **Shopping Cart:** Add, remove, and update quantities of products.
- **Checkout & Payments:** Complete order flow with a simulated payment gateway that generates receipts.
- **Order Management:** Users can view their order history and print/download receipts.
- **Seller Dashboard:** Sellers can upload new products, manage stock, and feature items in "Hot Deals".
- **Reviews & Ratings:** Users who have purchased an item can leave a star rating and review.
- **Modern UI:** Built with Bootstrap, custom CSS, and FontAwesome.

## 🛠️ Built With

- **Backend:** Python, Django
- **Frontend:** HTML, CSS, JavaScript, Bootstrap 4
- **Database:** SQLite (Development)
- **Icons:** FontAwesome
